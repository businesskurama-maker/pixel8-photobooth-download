# Pixel8 Photobooth for Windows

Photobooth software by **DinkyKong.pro**, developed by KITS. It has a live camera, countdown, retake, your own 4R layouts, a beauty filter, and silent printing to any Windows printer.

## Download

**[Download the installer (Windows 10/11, 64-bit)](https://github.com/businesskurama-maker/pixel8-photobooth-download/releases/latest/download/Pixel8Photobooth-Setup.exe)**

1. Run `Pixel8Photobooth-Setup.exe`. It adds a desktop icon and a Start menu entry.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**. Windows shows this for new apps until enough people have installed them.
3. Open the app and copy your **device code**.
4. Buy a license at **[dinkykong.pro/pixel8.photobooth](https://dinkykong.pro/pixel8.photobooth)**. Once it's approved, press **Get my key online** in the app.

To run the app without installing it, download `Pixel8Photobooth-Portable.exe` from the [latest release](https://github.com/businesskurama-maker/pixel8-photobooth-download/releases/latest).
